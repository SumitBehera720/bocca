# Farmart Frontend (React + Vite + Tailwind CSS)

Modern, fast, and responsive React frontend for the Farmart grocery supermarket platform.

## Architecture

- **Build Tool**: Vite
- **UI Framework**: React 18
- **Routing**: React Router DOM v6
- **Styling**: Tailwind CSS
- **Sliders**: Swiper
- **Notifications**: React Hot Toast
- **HTTP Client**: Axios

## Setup & Run

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Start Dev Server**:
   ```bash
   npm run dev
   ```

3. **Build Production Bundle**:
   ```bash
   npm run build
   ```

4. **Frontend App URL**: `http://localhost:5173`
